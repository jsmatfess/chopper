# Chopper 0.6.1

This patch improves Run and export recovery in the hosted workbench.

- The workbench acknowledges a Run after it sends the request to the worker. If
  dispatch fails, it clears stale analysis so you can retry with the current Job.
- Hosted export reads back the completion marker before reporting success and
  checks that its contents match the export.
- Native and browser regression tests cover output destination checks, the
  calculated-column schema boundary, and gzip manifest byte counts and advisory
  compressed targets.

Saved Jobs still use format version 1. The
[release-pinned schema](../job-json.md#editor-setup) describes the
same Job format as 0.6.0.
