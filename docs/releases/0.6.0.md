# Chopper 0.6.0

Chopper can now calculate columns from each input row in the hosted workbench
and native CLI. Use a calculated column in an export, reference it in another
formula, or use it in a pipeline step such as Filter or Partition.

## Calculated columns

- Define named columns in a [saved Job](../job-json.md#formulas) or
  through the [native CLI](../cli-reference.md). Chopper resolves dependencies
  between calculated columns and reports circular references.
- The [formula reference](../formula-functions.md) covers text, numbers,
  dates and timestamps, regular expressions, and null and error handling.
  Functions include examples with expected results.
- In the hosted editor, complete column and function names with Tab. Function
  help shows the arguments and examples as you type. The result preview uses
  values from a source row. Try another distinct row or type over a preview
  value to test an edge case.

## Hosted source exploration

The column explorer shows source columns as soon as the preview loads. Analyze
fills in value counts and shows its row counter while it runs. On wider screens
the explorer stays beside the Job editor. While editing a formula, click a
column name or value in the explorer to insert it.

## Compatibility

Saved Jobs still use format version 1. Existing supported Jobs can run as
written. Use the schema for the installed version and upgrade older binaries
before opening Jobs that use calculated columns. See the
[compatibility guide](../compatibility.md) for upgrading scripts and Jobs.
