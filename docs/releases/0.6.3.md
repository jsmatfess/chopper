# Chopper 0.6.3

The hosted workbench adds optional explanations for observed execution steps.
Select a step in Graph, List, or Timeline and open **Explain this step**.
Choose Brief, Standard, or Detailed with the three-stop slider.

The explanations use settings captured when Run began and observations from
that run. They can show what triggered a spill or grouping fallback when the
engine records the reason.

Saved Jobs use format version 1. Use the
[release-pinned schema](../job-json.md#editor-setup) for editor validation.
