# Chopper 0.6.2

This patch reduces memory overhead in native and hosted Runs and improves
large shuffles in the hosted workbench.

- Eligible standalone Uniform shuffles can avoid a spill at the same 1024 MiB
  memory request. The measured 800,000-row browser job finished a median
  7.6 seconds sooner through verified export.
- Hosted Runs copy fewer bytes during spill reads. A separate 3.2-million-row
  shuffle with a 512 MiB request saved a median 1.6 seconds through verified
  export.
- Native and hosted Runs carry the decoded Job's memory reservation into
  preparation. The browser also reuses its encoded Job buffers and streams
  reports, cutting temporary copies.
- Installed-browser checks cover quota errors, workspace and destination
  removal, and recovery on the same page.

Saved Jobs use format version 1. Use the
[release-pinned schema](../job-json.md#editor-setup) for editor validation.
