# Chopper 0.1.0

Status: released. [Native download](https://github.com/jsmatfess/chopper-private-archive/releases/tag/v0.1.0) and [hosted app](https://chopper-1rx.pages.dev/) are verified; see the [publication record](0.1.0-publication.json). The workspace and UI package
both identify as `0.1.0`. The final package receipt, rather than the version alone,
identifies the exact executable, hosted assets and source inputs; see the
[candidate receipt](0.1.0-candidate.json). Release gates are complete; deferred work remains in [TODO](../../TODO.md#release-validation).

## Delivered behavior

- **Run** validates and processes the current job without a separate confirmation
  step. Limits-only jobs using the default seeded policy stream directly to
  private staging. Other pipelines use the existing exact preparation path.
- **Analyze input** scans the whole input without preparing output CSVs.
  **Prepare exact outputs** retains exact encoded CSVs and boundaries for review.
  CLI `profile`, `analyze` and `run` preserve their documented distinctions.
- Reproducibility controls record the effective seed and algorithm version.
  Run and preparation retain a generated seed for export and reuse. CLI
  `--reproducible` requires the seeded policy.
- Explicit `memory_mb: "auto"` selects a conservative runtime-specific working
  budget. Numeric settings remain exact; explicit CLI memory/worker flags override
  imported settings. Omitted memory remains **256 MiB**. Automatic native worker
  selection remains capped at four; the hosted engine stays single-threaded.
- Exact balanced and interleaved splitting, explicit probabilistic allocation,
  partitioning, uniform shuffle and resident Fisher–Yates remain available.
  Probabilistic counts vary, particularly in small strata. Fisher–Yates fails
  clearly when its resident budget is insufficient.
- Strict byte caps count serialized, uncompressed CSV bytes, including headers,
  encoding, BOM, quoting and line endings. Compressed-byte targets are advisory.
- Native output publishes atomically without replacing an existing destination.
  Hosted output becomes complete only when its completion marker is committed.
  Failure and cancellation retain the documented cleanup behavior.

The corrected candidate also fixes premature shared-memory admission failure
for larger explicit budgets during partition/allocation/shuffle: the sorter
retains room to spill without changing numeric budgets or seeded CSV results.
See the [regression validation](../validation.md#explicit-memory-spill-regression-2026-10-28).
The revised receipt supersedes the original, unreleased candidate.

## Removed configurations

Saved jobs naming `buffer`, `buffer_rows`, `independent_buckets_v1`,
`blake3_xof_v1` or `shuffle_rng_buffer_bytes` fail strict decoding. CLI
`--shuffle buffer` and `--buffer-rows` fail explicitly. Select a supported option;
removed choices are never silently translated.

Removed experimental build features include radix/prefix distribution,
independent buckets/buffered XOF, partition-first, dormant Parquet wiring,
independent-parent batching/replay and direct compact/Arrow IPC input snapshots.
Parquet input is not supported. Historical experiments do not describe delivered
features. Surviving experimental strategies remain opt-in.

## Reproducibility and limits

The default `seeded_v1` policy preserves versioned logical results across supported
memory budgets and native sort-worker choices. Explicit `flexible_v1` is
experimental: a seed alone does not promise the same output across resource
plans, builds or runtimes. Compressed bytes can vary with codec versions.

Working-allocation reservations are not a complete process/RSS cap. Complete RSS
accounting, calibrated Auto defaults and broad device/scale guarantees are not
part of this release. The existing billion-row evidence applies only to its
recorded build and fixture.

Native setup targets 64-bit Windows, Linux and macOS; validation evidence is
specific to the builds and workloads recorded in [validation](../validation.md).
Local macOS release acceptance is deferred. The hosted app targets desktop
Chrome/Edge with the documented filesystem and export limits. The owner completed actual system-picker/external-destination smoke tests without
issues and approved this candidate. The hosted browser version was not reported.

See [browser support](../browser.md), [current contracts](../specification.md)
and [rollback preparation](../release-rollback.md) for operational details.
