# Chopper 0.4.0

Auto now parallelizes gzip and ZIP compression on the native CLI and in the hosted browser app. Large outputs can use workers within a single gzip stream or ZIP member. Prepared batches can also compress eligible outputs concurrently. Hosted Advanced settings let you limit compression workers, and the completed Run shows how many it used.

ZIP publication can write direct members into the private archive and buffer small prepared members in working memory. This reduces temporary reads and writes. The [compression investigation](../performance/investigations/parallel-gzip-and-zip-output-2026-11-22.md) documents complete-job timings, coverage and resource tradeoffs.

## Zstandard compatibility

Decompress existing Zstandard inputs before opening them in Chopper. Change the compression setting in saved Zstandard output jobs to gzip, ZIP or uncompressed before running them.
See the [migration and 0.3.0 pinning instructions](../compatibility.md#migrate-zstandard-jobs-from-03-to-04-or-later).

## Packages

The native packages contain the x86-64 Windows or Linux CLI. The Linux binary requires glibc 2.34 or later. The hosted browser bundle is separate. See the [CLI reference](../run-cli.md) and [browser requirements](../browser.md).
