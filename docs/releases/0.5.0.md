# Chopper 0.5.0

The 0.5 release focuses on installing Chopper, handing off a saved Job, and
verifying results from scheduled or recurring exports.

## Native CLI

- Windows and Linux archives include a [quickstart](../../README.md#native-quickstart)
  with a synthetic CSV, a saved Job and the version-matched
  [editor schema](../job-json.md#editor-setup).
- The [CLI reference](../cli-reference.md) comes from the released command help.
  The [Job recipes](../job-recipes.md) cover upload limits, partitioning and exact
  treatment/control allocation.
- `chopper split` has been removed. Use `run` for the same export pipeline.
  [Split migration guide](../compatibility.md#replace-split-with-run-in-05)
- [`chopper validate --config job.json`](../validate-cli.md) checks a saved Job
  without opening the source. Add `--json` for diagnostic codes and field paths.
- A Run targeting an already unusable output folder fails before reading CSV
  records. See the [destination rules](../run-cli.md).
- Run returns exit status `3` when output was committed and the stdout report
  failed. Use the [native manifest](../native-manifest.md) to verify the results
  before retrying. `--summary` gives Run and Analyze an aggregate-only stdout
  report for routine logs. Review stderr and manifests before sharing them.

See the [compatibility policy](../compatibility.md) for saved Jobs, automation and
the migration from Zstandard inputs or compression settings.

## Hosted

The picker explains how to retry when the browser blocks a destination. The
[export recovery guide](../browser.md#checking-a-hosted-export-after-interruption)
shows how to check `CHOPPER-COMPLETE.json` and recover after an interruption.

## Operator documentation

The [Chopper 0.5.0 operator site](https://chopper-docs.pages.dev/versions/0.5.0/)
brings the quickstart, CLI reference, Job recipes, browser export guidance,
and upgrade instructions together with search. The hosted app's **Docs** link
opens the guide for the running app version.
